
# Wasi Farabi | Personal Portfolio

A personal portfolio website showcasing my background, technical skills, projects, research, and creative work.

**Live Website:** [wasifarabi.vercel.app](https://wasifarabi.vercel.app)

## Overview

Built to bring together my work and interests across software development, data analytics, AI/ML research, and visual design. The website provides an overview of my experience, education, selected projects, and ways to connect with me.

## Features

- **About:** Introduction and professional interests.
- **Projects:** Selected academic and personal projects with relevant details and links.
- **Experience:** Professional experience, education, and leadership activities.
- **Research:** Overview of my undergraduate research.
- **Gallery:** A collection of selected creative and visual artwork.
- **Contact:** Links to my professional and social profiles.

## Tech Stack

- **Framework:** Next.js
- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel

## Run Locally

Clone the repository:

```bash
git clone https://github.com/farabi092/Portfolio.git
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
